Cirq en Google Colaboratory Colab

Una guía interactiva para simular circuitos cuánticos con Python

Cirq es una biblioteca de Python de código abierto desarrollada por Google Quantum AI para escribir, manipular y simular circuitos cuánticos. Esta página te muestra cómo usarla dentro del entorno gratuito de Google Colaboratory.

¿Qué hace esta página interactiva?
Puedes copiar cada bloque de código con un clic y pegarlo directamente en una celda de Colab. Además, las explicaciones son dinámicas: al hacer clic en algunos conceptos se despliegan detalles.

2. Conceptos fundamentales

Antes de programar, familiarízate con estos bloques:

Qubit
Unidad básica. En Cirq se crea con cirq.NamedQubit o cirq.GridQubit.
Momento
Conjunto de operaciones que actúan al mismo tiempo.
Circuito
Secuencia de momentos que representan el algoritmo cuántico.
Simulador
cirq.Simulator() ejecuta el circuito y obtiene resultados.

Puertas cuánticas más usadas

cirq.X   Pauli-X (NOT)
cirq.Y   Pauli-Y
cirq.Z   Pauli-Z
cirq.H   Hadamard
cirq.CNOT   Control-NOT
cirq.S / T   Fase
cirq.measure   Medición
cirq.rx, ry, rz

3. Primer circuito: qubit con puerta X

Vamos a crear un qubit, aplicarle una puerta X (que invierte el estado |0⟩ a |1⟩) y medir.

Ejemplo 1 – X gate y medición
import cirq # Crear un qubit q = cirq.NamedQubit('q') # Construir circuito circuito = cirq.Circuit( cirq.X(q), # Puerta X cirq.measure(q, key='resultado') ) print('Circuito:') print(circuito) # Simular sim = cirq.Simulator() resultado = sim.run(circuito, repetitions=10) print('\nResultados de 10 ejecuciones:') print(resultado.histogram(key='resultado'))

Verás que siempre sale 1 porque la puerta X cambió el estado inicial.

4. Estado de Bell (entrelazamiento)

El clásico: Hadamard en el primer qubit y luego CNOT para entrelazar.

Bell state |Φ⁺⟩
import cirq # Dos qubits q0, q1 = cirq.LineQubit.range(2) circuito_bell = cirq.Circuit( cirq.H(q0), cirq.CNOT(q0, q1), cirq.measure(q0, q1, key='bell') ) print(circuito_bell) sim = cirq.Simulator() resultados = sim.run(circuito_bell, repetitions=1000) conteo = resultados.histogram(key='bell') print('\nConteo de 1000 ejecuciones (00,01,10,11):') for bits, cuenta in sorted(conteo.items()): print(f'{bits:02b} : {cuenta}')

Observarás aproximadamente 50% 00 y 50% 11, sin estados intermedios.

5. Circuitos parametrizados

Cirq permite usar símbolos para construir circuitos que luego se evalúan con valores concretos.

Puerta Rx con parámetro
import cirq import sympy q = cirq.GridQubit(0, 0) theta = sympy.Symbol('theta') circ_param = cirq.Circuit(cirq.rx(theta)(q)) print('Circuito parametrizado:') print(circ_param) # Resolver para theta = π resolver = cirq.ParamResolver({'theta': 3.1416}) circ_resuelto = cirq.resolve_parameters(circ_param, resolver) print('\nCircuito con theta = π:') print(circ_resuelto)

Simulación de vector de estado

Para inspeccionar el estado cuántico completo:

Obtener vector de estado
import cirq q0, q1 = cirq.LineQubit.range(2) circ = cirq.Circuit(cirq.H(q0), cirq.CNOT(q0, q1)) sim = cirq.Simulator() result = sim.simulate(circ) print('Vector de estado final:') print(result.final_state_vector)

Preguntas frecuentes (click para expandir)

¿Qué diferencia hay entre run y simulate?
run ejecuta el circuito con mediciones y devuelve resultados clásicos (bits). simulate simula el estado cuántico completo (vector de estado) sin colapsar, ideal para depurar.
¿Puedo usar hardware cuántico real desde Colab?
Sí, mediante Quantum Engine de Google. Necesitas una cuenta y un proyecto en Google Cloud. Desde Colab puedes autenticarte y enviar trabajos a procesadores como Sycamore.
¿Cirq funciona con otras librerías como Qiskit?
No directamente, pero existen herramientas de conversión. Por ejemplo, qiskit y cirq tienen representaciones diferentes. Puedes usar cirq.contrib para interoperar.
